# Omni-Harvester Pro — Chrome Extension

## Install
1. Unzip the package.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the `omni-harvester-chrome-extension` folder.
6. Open Google Maps and use the **Omni-Harvester Pro** panel.

The extension preserves the supplied script's existing behavior, including country presets, filtering, CSV export, webhook sync, progress persistence, and CAPTCHA detection/alarm.

## Notes
- The extension only injects the supplied script on Google Maps.
- Google Maps DOM selectors can change over time, which may require maintenance.
- CAPTCHA/challenge pages are detected and require manual completion.
